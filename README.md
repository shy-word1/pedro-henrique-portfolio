## 01 / Sobre o projeto

E aí, eu sou o Pedro. Estudo Desenvolvimento de Sistemas e tô construindo meu caminho no front-end, um projeto de cada vez.

Esse portfólio é meu espaço pra juntar o que curto com o que tô aprendendo: interfaces dark, referências Y2K, glitch, anime, games, skate e cultura digital. A ideia é experimentar, testar e melhorar — sem ficar só na aparência: o site também tem que funcionar bem.

## 02 / O que tem por aqui

| Área | O que tu encontra |
| --- | --- |
| **Home** | Apresentação com estética dark e detalhes animados |
| **Sobre** | Um pouco de quem sou e do que curto |
| **Skills** | Tecnologias e ferramentas que venho estudando |
| **Projetos** | Cards com busca, filtros e demos interativas |
| **Web Lab** | Calculadora, lista de tarefas, gerador de senhas, Pomodoro, quiz e mais |
| **Personal Archive** | Referências de anime, games, skate e streetwear |
| **Contato** | Links pra conhecer meu trabalho e trocar uma ideia |

## 03 / Vibe & interface

- Preto, branco e vermelho como acento.
- Glitch em pontos específicos, sem deixar tudo piscando.
- Animações de entrada, hover e movimento suave.
- Layout responsivo pra desktop e celular.
- Respeito à preferência de movimento reduzido do sistema.
- Ferramentas do laboratório rodam no navegador; algumas listas ficam salvas localmente no dispositivo.

## 04 / Tecnologias

`React` · `Vite` · `JavaScript` · `CSS` · `HTML` · `Git/GitHub`

## 05 / Rodar localmente

Tu precisa ter o Node.js instalado.

```bash
git clone https://github.com/shy-word1/pedro-henrique-portfolio.git
cd pedro-henrique-portfolio
npm install
npm run dev
```

Pra gerar a versão de produção:

```bash
npm run build
npm run preview
```
